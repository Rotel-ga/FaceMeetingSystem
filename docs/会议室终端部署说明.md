# 会议室终端人脸识别签到部署说明

## 概述

本文档说明如何部署和配置会议室终端的人脸识别签到功能。该功能已集成到现有的会议室终端页面中，支持实时人脸识别签到。

## 功能特性

- ✅ 实时摄像头预览
- ✅ 百度人脸识别API集成
- ✅ 自动签到记录创建
- ✅ 会议权限验证
- ✅ 美观的成功/失败提示
- ✅ 开发模式模拟功能
- ✅ 灵活的配置管理

## 部署步骤

### 1. 后端API部署

确保后端服务已启动并包含以下API接口：

```
POST /api/checkin
```

**请求参数：**
- `image`: base64编码的图像数据
- `access_token`: 百度人脸识别API访问令牌

### 2. 前端配置

#### 2.1 环境变量配置

在项目根目录创建 `.env` 文件：

```env
# 百度人脸识别API访问令牌
VUE_APP_BAIDU_ACCESS_TOKEN=your_baidu_access_token_here
```

#### 2.2 终端配置文件

编辑 `src/config/terminal.js` 文件，根据需要调整配置：

```javascript
export const TERMINAL_CONFIG = {
  BAIDU_API: {
    ACCESS_TOKEN: process.env.VUE_APP_BAIDU_ACCESS_TOKEN || '',
    GROUP_ID: 'test', // 人脸库组ID
    THRESHOLDS: {
      MIN_SCORE: 80,
      LIVENESS: 'NORMAL',
      QUALITY: 'NORMAL'
    }
  },
  // ... 其他配置
}
```

### 3. 百度人脸识别API配置

#### 3.1 获取访问令牌

1. 登录百度AI开放平台
2. 创建人脸识别应用
3. 获取API Key和Secret Key
4. 调用令牌接口获取access_token

#### 3.2 创建人脸库

使用百度API创建人脸库，组ID设置为 `test`（或修改配置文件中的GROUP_ID）

#### 3.3 注册用户人脸

为系统中的用户注册人脸信息到百度人脸库中。

### 4. 硬件要求

#### 4.1 推荐配置

- **设备**: iPad或Android平板（10寸以上推荐）
- **摄像头**: 前置摄像头，分辨率不低于720p
- **网络**: 稳定的WiFi连接
- **浏览器**: Chrome、Safari、Edge等现代浏览器

#### 4.2 安装位置

- 会议室门口或入口处
- 摄像头高度约1.2-1.5米
- 光线充足，避免逆光
- 网络信号良好的位置

## 使用说明

### 1. 访问终端页面

在平板浏览器中访问：
```
http://your-frontend-url/room-terminal/{roomId}
```

### 2. 配置API令牌（首次使用）

1. 点击右侧"API配置"展开面板
2. 输入百度人脸识别API访问令牌
3. 配置完成后面板会自动收起

### 3. 进行人脸识别签到

1. 用户站在摄像头前
2. 点击"开始识别"按钮
3. 系统自动拍照并进行人脸识别
4. 显示识别结果和签到信息

## 开发模式

### 启用模拟功能

在开发环境中，如果未配置百度API令牌，系统会自动启用模拟模式：

- 模拟识别延迟（2秒）
- 可配置的成功率（默认70%）
- 随机生成识别分数
- 使用localStorage中的用户数据

### 调试功能

- 浏览器控制台查看详细日志
- 网络面板监控API调用
- 本地存储查看用户数据

## 故障排除

### 常见问题

#### 1. 摄像头无法启动

**解决方案：**
- 检查浏览器摄像头权限
- 确保使用HTTPS协议（本地开发可使用HTTP）
- 重新加载页面

#### 2. 人脸识别失败

**解决方案：**
- 检查网络连接
- 验证API访问令牌是否有效
- 确认用户人脸已注册到百度人脸库
- 检查光线条件

#### 3. 签到记录未创建

**解决方案：**
- 检查后端服务状态
- 验证用户是否有当前会议的签到权限
- 确认当前时间在会议时间范围内

### 日志查看

在浏览器开发者工具的控制台中查看详细的错误信息和调试日志。

## 安全注意事项

1. **API令牌安全**
   - 不要在代码中硬编码API令牌
   - 使用环境变量或安全的配置管理
   - 定期更新访问令牌

2. **网络安全**
   - 使用HTTPS协议
   - 配置适当的CORS策略
   - 限制API访问频率

3. **隐私保护**
   - 图像数据仅用于识别，不存储
   - 遵守相关隐私法规
   - 告知用户人脸识别的使用目的
