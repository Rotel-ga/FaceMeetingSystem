# 人脸识别功能使用说明

## 配置步骤

### 1. 获取百度AI API密钥
1. 访问 [百度AI开放平台](https://ai.baidu.com/)
2. 注册并登录账号
3. 创建应用，选择"人脸识别"服务
4. 获取 API Key 和 Secret Key

### 2. 配置环境变量
1. 复制 `.env.example` 文件为 `.env.local`
2. 在 `.env.local` 文件中填入真实的API密钥：
```
VUE_APP_BAIDU_API_KEY=你的API_KEY
VUE_APP_BAIDU_SECRET_KEY=你的SECRET_KEY
```

### 3. 重启开发服务器
配置完成后，重启前端开发服务器使环境变量生效。

## 功能使用

### 用户人脸注册
1. 登录管理员账号
2. 进入"用户管理"页面
3. 点击用户操作栏的"人脸注册"按钮
4. 按照提示完成人脸拍摄（需要拍摄3张照片）
5. 系统会自动选择质量最好的照片进行注册

### 会议室终端签到
1. 在首页点击"会议室终端"进入终端页面
2. 系统会自动启动摄像头
3. 点击"开始识别"按钮
4. 将人脸对准摄像头进行识别
5. 识别成功后会显示用户信息并记录签到

## 技术说明

### 人脸识别流程
1. **人脸注册**：使用百度人脸库管理API，将用户人脸信息注册到"meeting_users"人脸库
2. **人脸识别**：使用百度人脸搜索API，在人脸库中搜索匹配的用户
3. **相似度阈值**：设置为80%，超过此阈值才认为识别成功

### 数据存储
- 用户人脸token存储在localStorage的"users_data"中
- 签到记录存储在localStorage的"signInRecords"中
- 生产环境建议使用后端数据库存储

### 安全注意事项
1. API密钥应存储在环境变量中，不要硬编码在代码中
2. 生产环境建议通过后端API获取访问令牌
3. 建议定期更新API密钥
4. 人脸数据应遵循相关隐私保护法规

## 常见问题

### Q: 人脸识别失败怎么办？
A: 请检查：
- 光线是否充足
- 人脸是否正对摄像头
- 是否已完成人脸注册
- API密钥是否正确配置

### Q: 摄像头无法启动？
A: 请检查：
- 浏览器是否允许摄像头权限
- 设备是否有可用的摄像头
- 是否使用HTTPS访问（部分浏览器要求）

### Q: API调用失败？
A: 请检查：
- 网络连接是否正常
- API密钥是否正确
- 百度AI账户是否有足够的调用次数
