## 测试步骤

### 1. 后端服务测试

#### 启动后端服务
```bash
cd "d:/Cpp Project/FaceMeetingSystem/backend/build"
./FaceMeetingServer.exe
```

#### 测试用户登录API
```bash
# 测试管理员登录
curl -X POST http://localhost:18080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 测试普通用户登录
curl -X POST http://localhost:18080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user1","password":"password123"}'
```

#### 测试用户管理API
```bash
# 获取用户列表
curl -X GET http://localhost:18080/api/users

# 创建新用户
curl -X POST http://localhost:18080/api/users \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"testpass"}'

# 更新用户
curl -X PUT http://localhost:18080/api/users/3 \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser_updated","password":"newpass"}'

# 删除用户
curl -X DELETE http://localhost:18080/api/users/3
```

#### 测试会议室管理API
```bash
# 获取会议室列表
curl -X GET http://localhost:18080/api/rooms

# 创建新会议室
curl -X POST http://localhost:18080/api/rooms \
  -H "Content-Type: application/json" \
  -d '{"name":"测试会议室","capacity":10,"location":"3楼","equipment":"投影仪,白板"}'

# 更新会议室
curl -X PUT http://localhost:18080/api/rooms/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"更新会议室","capacity":15,"location":"4楼","equipment":"投影仪,白板,音响"}'

# 删除会议室
curl -X DELETE http://localhost:18080/api/rooms/1
```

#### 测试会议管理API
```bash
# 获取所有会议
curl -X GET http://localhost:18080/api/meetings

# 创建新会议
curl -X POST http://localhost:18080/api/meetings \
  -H "Content-Type: application/json" \
  -d '{"room_id":1,"title":"测试会议","time_start":"2024-01-20 10:00:00","time_end":"2024-01-20 11:00:00","organizer_id":1}'

# 获取会议室的会议
curl -X GET "http://localhost:18080/api/meetings/room/1?date=2024-01-20"

# 获取用户的会议
curl -X GET http://localhost:18080/api/meetings/user/1

# 更新会议
curl -X PUT http://localhost:18080/api/meetings/1 \
  -H "Content-Type: application/json" \
  -d '{"title":"更新会议","time_start":"2024-01-20 14:00:00","time_end":"2024-01-20 15:00:00"}'

# 删除会议
curl -X DELETE http://localhost:18080/api/meetings/1
```

#### 测试管理员会议审核API
```bash
# 获取待审核会议列表
curl -X GET http://localhost:18080/api/admin/meetings/pending

# 获取所有会议（管理员视图）
curl -X GET http://localhost:18080/api/admin/meetings

# 按状态筛选会议
curl -X GET "http://localhost:18080/api/admin/meetings?status=pending"
curl -X GET "http://localhost:18080/api/admin/meetings?status=approved"
curl -X GET "http://localhost:18080/api/admin/meetings?status=rejected"

# 批准会议
curl -X PUT http://localhost:18080/api/admin/meetings/1/review \
  -H "Content-Type: application/json" \
  -d '{"status":"approved"}'

# 拒绝会议
curl -X PUT http://localhost:18080/api/admin/meetings/2/review \
  -H "Content-Type: application/json" \
  -d '{"status":"rejected"}'
```

## API响应格式

### 登录成功响应
```json
{
  "id": 1,
  "username": "admin",
  "role": "admin",
  "face_token": ""
}
```

### 用户列表响应
```json
[
  {
    "id": 1,
    "username": "admin",
    "face_token": ""
  },
  {
    "id": 2,
    "username": "user1",
    "face_token": ""
  }
]
```
